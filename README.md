## ✨ Highlights & Features

- 🌗 **Interactive day/night switch in the hero** — Seamless switch between day and night video modes with choreographed motion.
- 📍 **Live visitor location + real-time weather widget** — Server-side geolocation and live weather with zero API keys required.
- 💬 **Dual Appointment Booking** — Automated background email delivery to HR plus 1-click direct WhatsApp routing (+91 88828 45860).
- 🎨 **Editorial design system** — Warm cream canvas, hairline borders, lightweight display typography, and restrained accents.
- ⚡ **HR + AI Visual Pipeline** — Interactive animated flow: `PEOPLE → DATA → AI → AUTOMATION → BETTER DECISIONS`.
- 🧩 **Skills & HR Knowledge** — Talent acquisition, HR operations, compliance (PF & ESIC fundamentals), and AI tools.
- 🪜 **Experience & Career Timeline** — Structured timeline ready for role highlights and achievements.
- 📅 **Appoint a Call Form** — Seamless appointment booking for client and recruiter consultations.

## 🚀 Running Locally

```bash

npm run dev

# TypeScript type check
npm run typecheck

# Production build
npm run build
```
