03 The Dual-Channel Appointment Booking System

The "Appoint a Call" system has been engineered with two simultaneous notification channels so Nityam Singh receives client leads instantly:

✉️ Channel 1: Automated Background Email

• Target Email: nityamkumarsingh31@gmail.com

• Subject: New Call Appointment Request – Nityam Kumar

• How it works: Upon form submission, the website executes a background API call via /api/appoint. An automated HTML email is sent with all 8 fields neatly formatted in a table.

• Spam Protection: Captcha-free serverless validation ensures prompt delivery directly to Gmail.

💬 Channel 2: Direct WhatsApp Instant Alert

• Target WhatsApp: +91 88828 45860

• On the Form: A "Book via WhatsApp" button allows visitors to open WhatsApp immediately with their details.

• On Confirmation: A prominent green button "Notify Nityam on WhatsApp Directly (1-Click)" lets the client alert Nityam immediately.

• Compatibility: Opens natively in the WhatsApp mobile app or WhatsApp Web on laptops.
